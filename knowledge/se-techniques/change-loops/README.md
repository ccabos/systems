# Change Loops

The loop you traverse to *change* an institution, as distinct from the
loop by which it runs. Its controlled process is not the world but the
institution's own rules.

- `overview.md` — operating loop vs change loop, what is recorded per lever, and the derived quantity
- `lever-inventory.md` — the method, the table shape, and one worked case
- `diagnostic-questions.md` — the five questions used to interrogate a proposed change
- `dangerous-patterns.md` — the two recurring patterns behind changes that never arrive
- `references.md` — sources

Applied in
`knowledge/system-catalogues/social-systems/corporation/change-loop-analysis.md`
(full lever inventory for one system) and
`knowledge/system-catalogues/social-systems/cross-system/change-loops-by-system.md`

For the loop this one acts on see `../control-structures/`. The

carry its connections — which is what makes the change loop a distinct
